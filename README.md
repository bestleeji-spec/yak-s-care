# 🌱 Yak-S Care

> 고조리서 기반 맞춤 약선 차 추천 및 찜하기

폴리텍대학 Vibe Coding 실습 프로젝트로 만든 단일 `index.html` 웹앱입니다.
현재 몸 상태를 고르면 『식료찬요』 등 고조리서·전통 식치 문헌을 참고한 약선 차를 추천하고, 마음에 드는 처방을 브라우저에 찜해 둘 수 있습니다.

**🔗 배포 주소: https://yak-s-care.vercel.app/**

## 주요 기능

- **증상 선택**: 피로회복 · 소화불량 · 면역력 강화 · 마음 안정 · 감기·목 건강 · 숙면
- **맞춤 약선 처방 확인**: 차 이름(한자), 참고 문헌, 재료, 효능, 달이는 법, 주의사항 표시
- **다른 처방 보기**: 증상별 2종의 차를 번갈아 추천
- **이 처방 찜하기**: `localStorage`에 저장 (중복 저장 방지)
- **나만의 찜한 약선 보관함**: 실시간 목록 렌더링, 항목별 [삭제] · 전체 비우기

## 기술 스택

- 순수 HTML · CSS · JavaScript (단일 `index.html`, 외부 라이브러리 없음)
- 데이터 저장: 브라우저 `localStorage` (백엔드/DB 없음)
- 배포: GitHub 연동 Vercel (push 시 자동 배포)

## 로컬에서 실행

저장소를 내려받은 뒤 `index.html`을 브라우저로 열면 바로 실행됩니다.

```bash
git clone https://github.com/bestleeji-spec/yak-s-care.git
```

## 참고 사항

- 찜 목록은 각 브라우저에만 저장되므로 기기·브라우저마다 따로 관리됩니다.
- 본 서비스는 교육용 실습 프로젝트이며, 의학적 진단·치료를 대신하지 않습니다.
